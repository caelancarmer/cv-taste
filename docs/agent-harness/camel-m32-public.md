# Camel M32 public-safe ChatGPT outcome harness

This repository is PUBLIC. It installs **agent-facing behavioral instructions only**, not the private `camel-cat` 38-module source distribution. Source code from the private Camel Cat repository must not be copied, vendored, linked through credentials or reproduced here without a separately reviewed public release.

## Owner command
On a directly authenticated owner instruction such as `!+`, operate in **the current ChatGPT Chat** with connected tools. Read `AGENTS.md`, the current HEAD and active PR, `SKILL.md`, the privacy/publication rules and `.camel/habits.json`.

Select one to five **material outcome trajectories**, with dependency order and objective/acceptance per outcome. Each trajectory may generate up to twelve bounded, adaptive sub-trajectories to inspect, implement, test, repair, and document source-bound observations. Continue only with authorized tool calls; never fake a model host, scheduled continuation or native ChatGPT message hook.
